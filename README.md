## ⚡ Engineering Focus & Systems Built From Scratch

I design and build **high-throughput backend infrastructure**, **distributed coordination engines**, and **security automation platforms**. Rather than relying on black-box abstractions, I build core systems from the wire protocol up:

- 🔌 **Wire Protocols & Storage Engines**: Implemented a Redis-compatible in-memory data store in pure Python & `asyncio` featuring a custom **RESP wire protocol parser**, min-heap TTL expiration, Append-Only File (AOF) durability, and Pub/Sub ([**TinyLite**](https://github.com/ayushdixit1-av/tinylite)).
- 🚀 **Ultra-Low-Latency Network Proxies**: Engineered a non-blocking API Gateway in **Java 21 & Netty NIO** achieving **`<2ms` proxy overhead** and **`18K+ RPS`** with distributed Redis token-bucket rate limiting and a 3-state Circuit Breaker ([**NexGate**](https://github.com/ayushdixit1-av/nexgate-api-gateway)).
- ⚙️ **Fault-Tolerant Job & Security Orchestration**: Built a zero-framework distributed task queue in **Python & Redis** with exponential-backoff retries, Dead-Letter Queues (DLQ), and heartbeat failover ([**Distributed Task Queue**](https://github.com/ayushdixit1-av/distributed-task-queue)), plus a 6-engine offensive security reconnaissance platform ([**OS3C**](https://github.com/ayushdixit1-av/os3c)).
- 🌐 **Portfolio**: **[ayushdixit1-av.github.io](https://ayushdixit1-av.github.io/)** &nbsp;|&nbsp; 📫 **Email**: **[ayushdixitvsecpanki@gmail.com](mailto:ayushdixitvsecpanki@gmail.com)**
